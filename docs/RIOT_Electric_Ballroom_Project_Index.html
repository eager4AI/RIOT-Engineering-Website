Engineering archive and resume map

This index is the entry point for the RIOT home-audio project. It records the current state of each subsystem, separates verified evidence from engineering targets, and identifies the first action required when work resumes.

Archive rule

The project dossier is the source of truth for accepted decisions and measured results. Chat discussions remain useful for exploration, but a decision is not considered closed until it is recorded in the relevant dossier.
