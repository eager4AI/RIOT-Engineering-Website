RIOT bench use

The DOS1102S is intended for waveform, clipping, gain, and oscillation checks. Begin with the instrument’s calibration output and verify probes before testing an amplifier. Use appropriate dummy loads for amplifier output tests.

Access: the guide file is in the private Archive repository. Sign in to GitHub with an account that has access to eager4AI/RIOT-Engineering-Archive to open or download it.

Guide source: owner-supplied photographed pages. Check the ratings printed on the actual scope and probes before connecting them.
