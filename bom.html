Ciuffoli source BOM · Andrea Ciuffoli PF2019 / E180F release

The primary source calls this a single-ended Class A hybrid power follower, not a push-pull design. It specifies a single-channel current-amplifier PCB whose parts list must be duplicated for stereo, plus a separate PCB described as two-channel with its list complete. The source does not name that second PCB in the BOM paragraph, so it is kept separate here without assigning an unverified function. Distributor SKUs and values below are transcribed as published; conflicts and uncertain entries are flagged.
