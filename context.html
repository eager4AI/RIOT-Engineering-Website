RIOT agent context

Canonical instructions and project map for Stefano and authorised AI agents.

Canonical files

  • RIOT_PROJECT_CONTEXT.md — working rules, system baseline and evidence boundaries
  • RIOT_DOCUMENT_INDEX.json — project-to-document map
  • AGENTS.md — instructions for agents working in this repository

Important boundary

These files are the durable repository context. A chat must have access to the repository or its attached files to use them; they do not silently appear in unrelated conversations.
